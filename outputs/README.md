# 运行输出

每次运行单独保存，目录名是北京时间，例如 `2026-11-01_21-30-00`，同秒运行会自动加序号，不覆盖已有记录。

**团队已完成的 TIA 128 项实验见 [tia_32x4_20261108_results/](tia_32x4_20261108_results/README.md)。** 每组含 32 题，模型为 deepseek-v4.1-flash-1017 与 qwen3.8-flash，作者框架为 self 与 Codex。部分 JSON 采用 gzip，逐文件摘要见该目录 manifest.json。

[published/](published/README.md) 保存本机单模型重复计划和形式化工具对照。完整运行路径及协议见 [单模型重复入口](../docs/TIA_MATRIX_32X4.md)。

- `single/时间戳_题号/`：一次单题运行。
- `campaigns/时间戳/`：一次完整的四组对照实验。
- `tia_matrix/时间戳_deepseek_flash/`：TIA 单模型、两框架、两次独立重复的原始实验输出。
- `published/实验目录名/`：可提交到 GitHub 的证据快照及哈希清单。

## 批量实验先看哪里

1. `SUMMARY.md`：整轮实验的状态和四组结果摘要。
2. `results.csv`：每一道题、每个框架和模型的结果与失败原因，可用Excel打开。
3. `tasks/01_CUSTOM_01/self_A/`：按题号和框架/模型分组的具体运行。

每题外层只显示：

- `SUMMARY.md`：这题是否通过、失败原因、编译/测试/LTL结果。
- `final.st`：这次最终保留的ST代码，失败或取消时不表示已验证通过。
- `run.log`：按时间记录的生成、修改和检查过程。
- `details/`：需要追查时再打开。

`details/receipt.json`为完整最终结论，`metrics.json`为统计指标，`events.jsonl`为程序分析用日志；`requests/`保存模型请求及响应，`submissions/`保存每个提交版本和编译、仿真、形式化检查证据。这些内容不再散落在外层。

整轮的 `details/` 统一保存模型配置、题目快照、进度和CODESYS启动检查；不再给每题重复保存相同题库。

## 停止与历史

- 暂停：停止领取新任务，等待当前任务正常完成后停在可继续状态；服务需保持运行。
- 继续：继续该轮剩余任务，已完成任务不重跑。
- 结束实验：取消未完成任务；不能原地继续，已有文件保留。
- 关闭网页服务：空闲时关闭后台服务；或在启动终端按Ctrl+C，程序会请求取消任务并等待保存。

重新打开后，已保存的历史仍会显示。只有主动清空记录会隐藏历史；清空不会删除磁盘文件。
