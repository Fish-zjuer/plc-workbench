# 文件导入与动态题数实验

网页每次打开或刷新从空题目列表开始，只通过“选择文件”导入本机数据。没有预设题库按钮，也不会自动恢复旧导入目录。旧题库快照和实验文件仍保存在服务端供已有记录追溯，不会被删除。

## 导入

可选一个完整JSON题库，也可多选题目、测试、LTL和约束JSON。题数由文件内容决定，例如16题或160题。点击“下载题库模板”查看完整字段示例；每题需要唯一id、block、requirements、interface，可附ltl、constraints和scenarios。没有测试的任务只报告编译结果，不冒充功能测试通过。

单独LTL/Markdown/TXT用于给当前选中题目补充材料。完整题目JSON支持单对象、数组或包含tasks列表的对象。浏览器导入文件总文本最多128MB、最多1000个文件；这是资源限制，不是题目数量限制。特殊结构体/VARIANT测试桥仍受后端接口支持范围约束。

## 2×2

导入成功后，在“实验记录”填写两个模型ID，范围默认“本次导入的全部题目”，也可选“当前题库版本全部题目”或“当前题目”。页面动态显示N题×2框架×2模型=4N次任务，不限定课程题号或32题。

多个完整题库依次导入时追加到本次页面列表；每次导入产生独立快照。刷新页面会清空本次选择，再次实验需重新选择电脑文件导入。实验历史仍单独保留。

升级后需关闭旧服务窗口、重新双击launch-web.cmd并刷新浏览器；仅刷新不能更新Python后端。
