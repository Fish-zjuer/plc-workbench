# TIA 原生运行环境

当前验收使用 TIA Portal / Openness V21、PLCSIM Advanced V8、CPU 1511-1 PN / V2.9 专用仿真模板。S7-1200 模板用于候选源码编译。安装目录、项目路径和许可证属于本机配置，不提交至仓库。

## 执行与资源

`TiaBridge.exe` 在完整工程副本上生成块、编译并导出虚拟存储卡，关闭自身 Portal 后，`TiaRuntime.exe` 以独立进程注册仿真实例、上电、执行、读取输出，最后关机、注销。运行器不引用 Openness。卡清单绑定源码、测试驱动、工具二进制和卡内容散列。

多场景开放数组使用每场景独立的卡与调用方存储，完整运行后统一判卷。所有批次共用总预算及绝对截止时间。Windows 用户级字节锁串行化网页、CLI 与不同 checkout 的 TIA 会话；取消和清理只作用于本次创建的进程及实例。

## 配置

构建 Bridge 时设置 `OpennessDir` 为已安装 V21 的 `net48` API 目录。在工作台配置 Bridge、编译模板、专用 S7-1500 仿真模板及 PLCSIM Advanced x64 API。模板关闭并保存，输出位于模板目录外。

首次 Openness 授权由使用者处理。试用剩余天数提示可使用 [有限监听器](TIA_TRIAL_ACK.md)确认。辅助工具不自动接入 Trial/Campaign，不操作权限、密码或激活窗口。

## 最终结果

默认开放数组正例完成编译、320 次原生调用和基线配置下的 8 条有界性质检查；负对照被原生判据拒绝。其余已验收行为及状态机结果见 [最终报告](../reports/tia_final_20261104/README.md)。这些结果是本机有限仿真与源模型检查，不代表实体 PLC 或全部运行条件。
