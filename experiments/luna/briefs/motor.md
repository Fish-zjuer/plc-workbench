Design a motor start-stop control function block, which includes three Boolean inputs: StartBtn for the start button, StopBtn for the stop button, and EStop for the emergency stop signal, as well as a Boolean output Motor for the motor's operating status. The motor is in a stopped state when the system is initialized. When the start button is pressed and neither the stop button nor the emergency stop signal is triggered, the motor starts; after the start button is released, the motor maintains its operating status. When the stop button is pressed or the emergency stop signal is triggered, the motor stops, and the stop and emergency stop have higher priority than the start.

Submission packaging only: use FUNCTION_BLOCK MotorControl. Inputs StartBtn, StopBtn, EStop are BOOL. Output Motor is BOOL. Local internal state may be added. Target CODESYS ST.
