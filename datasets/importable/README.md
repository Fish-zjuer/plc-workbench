# 可导入题库

- `course32_20261030.json`：当前推荐，队友2026-10-30交付的完整题目、测试、LTL、溯源合并包，20道公共题＋12道自建题。
- `course32_baseline.json`：保留的早期题库版本，用于复现历史输入，不应与新版成绩混用。

在网页“题库与规约”选择一个 JSON 导入，不要同时导入两包再当作32题。网页初始仍为空，不自动加载这些文件。可导入其他题数的兼容文件。

原始队友交付资料保存在 `../team_delivery_20261030/`；早期冻结数据仍在 `../standalone32/`。`../reproduction_manifest.json` 保存文件字节和SHA256。包内 execution_status 等历史元数据不代表在新机器运行通过。
